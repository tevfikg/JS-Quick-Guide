# JavaScript Fundamentals Learning Platform

## Overview
This project is an interactive learning platform for JavaScript fundamentals. It provides a hands-on approach to learning key JavaScript concepts with embedded code playgrounds that allow users to practice writing and running code directly in the browser.

## Features
* **Interactive Code Playgrounds**: Try and run JavaScript code directly in the browser
* **11 Core JavaScript Concepts** covered with examples and exercises:
   1. Variables and Data Types
   2. Functions (regular, arrow, one-line arrow)
   3. Conditional Statements
   4. Loops
   5. Array Methods
   6. DOM Manipulation
   7. Array/Object Destructuring
   8. Built-in Methods
   9. Dates
   10. Regular Expressions
   11. Type Conversions
* **Solution Toggle**: View provided solutions or try to solve exercises on your own
* **Custom Styling**: Modern UI with custom scrollbars and intuitive layout
* The project uses SCSS (Sass) for styling
